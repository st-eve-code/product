# Product

A mobile app built with Expo and Expo Router, with sign-in and account screens.

## Screens

- **Welcome** (`app/index.tsx`)
- **Login** and **Register**
- **Forgot password**, **OTP confirmation** and **Reset password**

Shared form pieces, such as the header, input field, checkbox, and submit button, are in `app/authComponent/`.

## Tech stack

- Expo and React Native
- Expo Router for navigation
- React Navigation

## Getting started

```bash
npm install
npx expo start
```

Then open the app in Expo Go, an Android emulator, or an iOS simulator.

## Scripts

| Command | Description |
| --- | --- |
| `npm start` | Start the Expo development server |
| `npm run android` | Open the app on Android |
| `npm run ios` | Open the app on iOS |
| `npm run web` | Open the app in the browser |
| `npm run lint` | Run ESLint |
